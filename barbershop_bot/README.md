# Telegram-бот записи для барбершопа

Бот принимает записи клиентов, показывает прайс и контакты, позволяет отменять визиты, уведомляет владельца и отправляет клиентам напоминания накануне записи.

Технологии: Python, aiogram 3, SQLite. Настройки салона вынесены в `settings.json`, поэтому название, услуги, цены и расписание можно менять без правки логики бота.

## 1. Возможности

- Запись по схеме: **услуга → дата → свободное время**.
- Автоматическое скрытие уже занятых слотов.
- Просмотр и отмена собственных записей клиентом.
- Уведомления владельцу о новых записях и отменах.
- Команды владельца `/today` и `/week`.
- Напоминания клиентам за день до визита.
- Хранение записей в одном файле SQLite `bookings.db`.

## 2. Что понадобится

- Windows 10/11.
- Python 3.10 или новее: <https://www.python.org/downloads/>. При установке включите **Add Python to PATH**.
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).
- Числовой Telegram-ID владельца.

## 3. Установка и первый запуск на Windows

### 3.1. Откройте папку проекта

```bat
cd "C:\Projects\работа\barbershop_bot"
```

Все следующие команды выполняйте именно из этой папки: файл базы данных создаётся относительно текущей рабочей директории.

### 3.2. Создайте виртуальное окружение и установите зависимости

```bat
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если папка `venv` уже существует, заново создавать её не обязательно. Достаточно выполнить вторую команду.

### 3.3. Настройте доступ к Telegram

Скопируйте пример конфигурации:

```bat
copy .env.example .env
notepad .env
```

Укажите реальные значения:

```dotenv
BOT_TOKEN=123456:ABC-your-real-token
OWNER_ID=123456789
```

- `BOT_TOKEN` — токен, выданный `@BotFather`.
- `OWNER_ID` — числовой ID аккаунта владельца; его можно узнать, например, через `@userinfobot`.

Не используйте кавычки и не оставляйте примерные значения. Не публикуйте `.env` и токен бота.

Откройте своего бота в Telegram под аккаунтом владельца и нажмите **Start** / «Запустить». Это необходимо для получения уведомлений.

### 3.4. Проверьте настройки салона

Откройте `settings.json` и замените демонстрационные данные:

```json
{
  "shop_name": "Барбершоп «Пример»",
  "address": "📍 ул. Примерная, 1",
  "phone": "📞 +7 900 000-00-00",
  "work_hours": "🕙 Ежедневно 10:00–20:00",
  "services": [
    { "key": "cut", "title": "Стрижка", "price": 1500 },
    { "key": "beard", "title": "Борода", "price": 800 },
    { "key": "combo", "title": "Стрижка + борода", "price": 2100 }
  ],
  "times": ["10:00", "12:00", "14:00", "16:00", "18:00"],
  "booking_days_ahead": 7
}
```

Правила:

- `key` — короткий уникальный латинский идентификатор услуги без пробелов;
- `price` — целое число в рублях без символа `₽`;
- `times` — время в 24-часовом формате `ЧЧ:ММ`;
- `booking_days_ahead` — на сколько дней вперёд открыта запись;
- JSON не допускает запятых после последнего элемента списка или объекта.

### 3.5. Запустите бота

```bat
venv\Scripts\python.exe bot.py
```

Оставьте терминал открытым. Пока процесс работает, бот принимает сообщения и отправляет напоминания. Для остановки нажмите `Ctrl+C`.

Настройки `settings.json` читаются при старте: после их изменения бота нужно перезапустить.

## 4. Инструкция для клиента

1. Откройте бота и отправьте `/start` или нажмите **Start**.
2. Нажмите **«Записаться»**.
3. Выберите услугу.
4. Выберите дату. В текущей версии предлагаются даты начиная с завтрашнего дня; горизонт задаётся параметром `booking_days_ahead`.
5. Выберите свободное время. Если все слоты заняты, выберите другой день.
6. Дождитесь сообщения «Готово, вы записаны!».

Дополнительные кнопки:

- **«Мои записи»** — показывает текущие и будущие записи и позволяет отменить их;
- **«Прайс»** — выводит услуги и цены из `settings.json`;
- **«Контакты»** — показывает адрес, телефон и график;
- **«✖ Отмена»** на этапе выбора услуги — прерывает оформление записи;
- **«◀ Назад»** — возвращает на предыдущий шаг.

Чтобы получить напоминание, не блокируйте бота после записи.

## 5. Инструкция для владельца

Команды доступны только аккаунту, чей ID указан в `OWNER_ID`:

| Команда | Результат |
|---|---|
| `/today` | Записи на сегодня, отсортированные по времени |
| `/week` | Записи с сегодняшнего дня по седьмой следующий день включительно |

Владелец автоматически получает сообщения:

- «Новая запись» после успешного выбора времени;
- «Клиент отменил запись» после отмены клиентом.

Отдельного административного сайта или команды ручного добавления записи в текущей версии нет.

## 6. Как работают напоминания

- Раз в час бот ищет записи на завтрашний день, для которых напоминание ещё не отправлялось.
- После успешной отправки запись помечается флагом `reminded=1`.
- Напоминание приходит в Telegram клиента за день до визита, в момент ближайшей hourly-проверки.
- Бот должен быть запущен. Если он выключен весь предыдущий день, напоминание за день до визита не будет отправлено.
- Если клиент заблокировал бота, отправка пропускается.

## 7. Настройка под другой салон

Обычно достаточно изменить `settings.json` и перезапустить бота.

| Задача | Где менять |
|---|---|
| Название, адрес, телефон, график | `settings.json` |
| Услуги, цены и идентификаторы услуг | `settings.json`, массив `services` |
| Рабочие слоты | `settings.json`, массив `times` |
| Горизонт записи | `settings.json`, `booking_days_ahead` |
| Тексты сообщений и кнопок | `bot.py` |
| Периодичность и текст напоминаний | `bot.py`, функция `reminder_loop()` |

Поле `shop_name` сейчас сохранено как настройка, но в текстах интерфейса фактически не выводится; название можно добавить в обработчик `/start` в `bot.py`.

## 8. Данные и резервное копирование

| Файл | Что содержит | Что делать |
|---|---|---|
| `bookings.db` | Клиентские записи и статус напоминаний | Регулярно копировать и беречь как персональные данные |
| `settings.json` | Настройки салона | Включить в резервную копию |
| `.env` | Токен и ID владельца | Хранить отдельно и не публиковать |
| `bot.py` | Логика бота | Сохранять вместе с проектом |

Перед резервным копированием `bookings.db` желательно остановить бота, чтобы копия была согласованной. Для восстановления остановите бота, верните файл на прежнее место и запустите его снова.

Если `bookings.db` отсутствует, при запуске создаётся новая пустая база. Не удаляйте существующий файл, если записи ещё нужны.

## 9. Постоянная работа на сервере

Для круглосуточной работы:

1. Перенесите проект на сервер с Python.
2. Установите зависимости в виртуальное окружение.
3. Настройте `.env` и `settings.json`.
4. Запускайте `bot.py` как службу с автоматическим перезапуском.
5. В качестве рабочей директории службы укажите папку проекта.
6. Настройте резервное копирование `bookings.db`.
7. Не запускайте одновременно две копии с одним токеном: они будут конкурировать за получение обновлений Telegram.

Бот использует long polling; отдельный webhook и открытый HTTP-порт не требуются.

## 10. Типичные проблемы

### `python` не распознаётся

Установите Python с опцией **Add Python to PATH**, перезапустите терминал или попробуйте `py` вместо `python`.

### Бот не запускается из-за `OWNER_ID`

Убедитесь, что `.env` находится рядом с `bot.py`, а `OWNER_ID` содержит только число, без пробелов, кавычек и текста.

### Ошибка токена или бот не отвечает

Проверьте токен в `.env`, доступ к `api.telegram.org`, интернет-соединение и отсутствие второй запущенной копии бота с тем же токеном.

### Владельцу не приходят уведомления

Проверьте `OWNER_ID` и нажмите **Start** в диалоге с ботом под аккаунтом владельца. Затем создайте тестовую запись с другого аккаунта.

### Изменения в `settings.json` не применяются

Проверьте синтаксис JSON и перезапустите бота. Особенно часто ошибку вызывает лишняя запятая в конце списка.

### Создалась новая пустая база

Скорее всего, бот запущен не из папки проекта. Остановите его, перейдите в `C:\Projects\работа\barbershop_bot` и запустите снова. Не перезаписывайте старую базу новой, пока не проверите обе.

### Клиент не получил напоминание

Проверьте, работал ли бот накануне визита, не заблокирован ли он клиентом и отмечена ли запись на нужную дату.

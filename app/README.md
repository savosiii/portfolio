# «Айра» — веб-чат для консультаций и сбора заявок

Проект состоит из двух независимых частей:

1. **Веб-чат** (`index.html`, `src/main.js`, `src/config.js`) — отвечает на вопросы по заданным правилам, показывает услуги и принимает контакты клиента.
2. **Приёмник заявок** (`relay_bot.py`) — необязательный локальный сервер, который пересылает заявки в Telegram владельца.

> Это демонстрационный сценарный бот, а не подключённая языковая модель. Ответы определяются ключевыми словами и шаблонами из `src/config.js`.

## 1. Что понадобится

- Windows 10/11.
- Python 3.10 или новее для запуска сайта и `relay_bot.py`: <https://www.python.org/downloads/>. При установке включите **Add Python to PATH**.
- Современный браузер: Chrome, Edge, Firefox или аналог.
- Для отправки заявок в Telegram — бот, созданный через [@BotFather](https://t.me/BotFather), и числовой Telegram-ID владельца.

Node.js и npm для обычного локального запуска не нужны. Они требуются только для необязательной сборки через Vite.

## 2. Быстрый запуск демо без Telegram

В демо-режиме чат работает полностью в браузере. Заявки сохраняются только в `localStorage` текущего браузера и никому не отправляются.

1. Откройте терминал в папке проекта:

   ```bat
   cd "C:\Projects\работа\app"
   ```

2. Запустите локальный веб-сервер:

   ```bat
   python -m http.server --bind 127.0.0.1 8001
   ```

3. Не закрывая терминал, откройте в браузере:

   <http://localhost:8001/>

4. Проверьте кнопки «Услуги и цены», «График работы», «Контакты», «Оставить заявку» и «Главное меню».

5. Для остановки сервера вернитесь в терминал и нажмите `Ctrl+C`.

Не открывайте проект двойным щелчком по `index.html`: из-за JavaScript-модулей корректный запуск следует выполнять через локальный HTTP-сервер.

Если на компьютере установлен Node.js, также доступен запуск через Vite:

```bat
npm install
npm run dev -- --host 127.0.0.1 --port 7100
```

В этом случае откройте <http://localhost:7100/>. Если PowerShell сообщает `npm : Имя "npm" не распознано`, используйте основной вариант через Python выше или установите Node.js и перезапустите терминал. Для необязательной production-сборки используйте `npm run build`: готовые статические файлы появятся в папке `dist`.

## 3. Настройка текста, услуг и контактов

Все основные данные находятся в `src/config.js`, в объекте `DEFAULT_CONFIG`.

| Параметр | Что изменить |
|---|---|
| `companyName` | Название компании |
| `botName` | Имя виртуального консультанта |
| `tagline` | Подпись под именем бота |
| `workHours` | График работы |
| `phone`, `email`, `address` | Контактные данные |
| `services` | Список услуг: `name`, `desc`, `price` |
| `faq` | Ключевые слова и ответы на частые вопросы |
| `leadWebhook` | Адрес приёмника заявок; пустая строка включает демо-режим |

Пример услуги:

```js
{ name: 'Консультация', desc: 'Разбор задачи за 30 минут.', price: 'бесплатно' },
```

Пример обычного вопроса и ответа:

```js
{
  keys: 'доставка, доставите, срок доставки',
  answer: 'Доставляем по городу за 1–2 рабочих дня.',
  dynamic: '',
},
```

В `keys` ключевые слова перечисляются через запятую. Лучше использовать основы слов: например, `оплат` будет находиться и в слове «оплата», и в слове «оплатить».

Значение `dynamic` задаёт готовый сценарий:

- `services` — список услуг;
- `lead` — форма заявки;
- `hours` — график;
- `contacts` — контакты;
- `human` — предложение связаться с менеджером;
- `greeting` — приветствие;
- пустая строка — обычный текст из `answer`.

После изменения файла сохраните его и обновите страницу браузера сочетанием `Ctrl+F5`. Если браузер продолжает показывать старую конфигурацию, очистите данные сайта для `localhost`: ранее сохранённая конфигурация `botcfg` в `localStorage` имеет приоритет над значениями по умолчанию.

## 4. Подключение доставки заявок в Telegram

### 4.1. Создайте Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather).
2. Выполните команду `/newbot` и следуйте его указаниям.
3. Скопируйте выданный токен. Никому его не публикуйте.
4. Узнайте свой числовой ID, например через `@userinfobot`.
5. Откройте созданного бота под аккаунтом владельца и нажмите **Start** / «Запустить». Иначе Telegram может не разрешить боту отправить вам сообщение.

### 4.2. Создайте файл `.env`

В папке `C:\Projects\работа\app` создайте файл `.env` со следующим содержимым:

```dotenv
BOT_TOKEN=123456:ABC-your-real-token
CHAT_ID=123456789
PORT=8787
```

Замените значения на свой токен и ID. Угловые скобки, кавычки и пробелы вокруг `=` не нужны.

Файл `.env` содержит секретный токен: не отправляйте его в Git, мессенджеры и общие архивы.

### 4.3. Укажите адрес приёмника

В `src/config.js` замените:

```js
leadWebhook: '',
```

на:

```js
leadWebhook: 'http://127.0.0.1:8787/lead',
```

Этот адрес подходит, когда сайт и приёмник запущены на одном компьютере.

### 4.4. Запустите обе части проекта

В **первом терминале** установите модуль чтения `.env` и запустите приёмник:

```bat
cd "C:\Projects\работа\app"
python -m pip install python-dotenv
python relay_bot.py
```

Для проверки откройте <http://localhost:8787/>. Должен вернуться JSON с `"ok": true` и `"telegram": true`.

Во **втором терминале** запустите сайт:

```bat
cd "C:\Projects\работа\app"
python -m http.server --bind 127.0.0.1 8001
```

Откройте <http://localhost:8001/>, отправьте тестовую заявку и убедитесь, что сообщение пришло владельцу в Telegram.

Оба процесса должны работать одновременно. Останавливаются они сочетанием `Ctrl+C` в соответствующем терминале.

## 5. Как пользоваться чатом

1. Клиент задаёт вопрос текстом или выбирает быструю кнопку.
2. Бот ищет совпадения с ключевыми словами из `faq` и показывает наиболее подходящий ответ.
3. Если совпадений нет, бот предлагает оставить заявку или посмотреть услуги.
4. Кнопка **«Главное меню»** в шапке чата и одноимённый быстрый ответ возвращают четыре основных действия. Переписка при этом сохраняется. На узком экране в шапке отображается иконка дома с той же функцией.
5. В форме клиент указывает имя, телефон и, при желании, вопрос.
6. Заявка сначала сохраняется в браузере, затем отправляется на `leadWebhook`, если адрес настроен.
7. `relay_bot.py` передаёт имя, телефон, вопрос, компанию и адрес страницы в Telegram.

Телефон должен начинаться с цифры или `+` и содержать не менее 10 символов из числа цифр, пробелов, скобок и дефисов.

## 6. Где хранятся заявки

Локальные копии находятся в `localStorage` браузера под ключом `leads`. Счётчик в правой части шапки показывает их количество.

Важно:

- данные привязаны к конкретному браузеру, устройству и адресу сайта;
- при смене порта, домена, браузера или очистке данных сайта список будет другим или исчезнет;
- встроенного экрана просмотра всех сохранённых заявок и экспорта в CSV/Excel нет;
- автоматической повторной отправки заявки после восстановления связи нет.

Для технической проверки локальных записей можно открыть консоль разработчика браузера (`F12`) и выполнить:

```js
JSON.parse(localStorage.getItem('leads') || '[]')
```

## 7. Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | Разметка, стили и формы интерфейса |
| `src/main.js` | Сценарий диалога, главное меню, валидация, хранение и отправка заявок |

## 8. Резервное копирование и перенос

Для переноса исходников скопируйте:

- `index.html`;
- папку `src`;
- `package.json` и `package-lock.json`;
- `relay_bot.py`;
- `.env` — только по защищённому каналу, если нужно сохранить настройки Telegram.

Локальные заявки из `localStorage` при копировании файлов не переносятся. Их нужно экспортировать отдельно или считать Telegram основным местом получения заявок.

## 9. Публикация на сервере

Перед публичным запуском необходимо:

1. Разместить статические файлы сайта на HTTPS-хостинге.
2. Запустить `relay_bot.py` как постоянную службу с рабочей папкой `app`.
3. Настроить обратный прокси и HTTPS для `/lead`; при HTTPS-сайте браузер может заблокировать обычный HTTP-webhook.
4. В `leadWebhook` указать публичный HTTPS-адрес приёмника.
5. Ограничить доступ к приёмнику: сейчас разрешены запросы с любых источников (`CORS: *`), нет авторизации, защиты от спама и ограничения частоты запросов.
6. Проверить журнал службы и реальную доставку тестовой заявки в Telegram.

Не выставляйте текущий приёмник в открытый интернет без этих мер.

## 10. Типичные проблемы

### `python` не распознаётся

Переустановите Python с опцией **Add Python to PATH**, перезапустите терминал или попробуйте команду `py` вместо `python`.

### Страница открывается, но скрипты не работают

Убедитесь, что используется `http://localhost:8001/`, а не путь `file:///.../index.html`.

### Заявка сохраняется, но не приходит в Telegram

Проверьте:

- запущен ли `python relay_bot.py`;
- указан ли правильный `leadWebhook`;
- возвращает ли <http://localhost:8787/> значение `"telegram": true`;
- верны ли `BOT_TOKEN` и `CHAT_ID` в `.env`;
- нажимал ли владелец «Запустить» в диалоге с ботом;
- доступен ли `api.telegram.org` с компьютера;
- совпадает ли схема сайта и webhook: HTTPS-сайту нужен HTTPS-webhook.

### Ошибка доступа к порту (`WinError 10013`) или порт занят

Windows может резервировать некоторые порты для системных служб, Hyper-V или WSL. Запуск от имени администратора обычно не нужен — выберите другой порт. На текущем компьютере порт `8000` заблокирован, а `8001` доступен, поэтому для сайта используйте:

```bat
python -m http.server --bind 127.0.0.1 8001
```

После этого открывайте <http://localhost:8001/>. Если и этот порт недоступен, попробуйте `8080` и измените номер в адресе страницы.

Для приёмника измените `PORT` в `.env` и одновременно обновите порт в `leadWebhook`. Порт приёмника `8787` на текущем компьютере доступен, поэтому при ошибке только веб-сервера менять его не требуется.

### После правок ничего не изменилось

Сохраните `src/config.js`, обновите страницу через `Ctrl+F5` и при необходимости очистите данные сайта `localhost` в браузере.

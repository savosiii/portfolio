# Портфолио

Пет-проекты: чат-виджет для сайта и два Telegram-бота на Python.

## Проекты

### 1. [app](app) — «Айра», веб-чат для консультаций и сбора заявок

Сценарный чат-виджет для сайта компании: отвечает на вопросы по заданным правилам, показывает услуги и принимает контакты клиента. Заявки можно пересылать владельцу в Telegram через локальный приёмник `relay_bot.py`.

- **Технологии:** JavaScript (ванильный + Vite), Python.
- **Запуск:** локальный сервер `python -m http.server`, демо работает без Telegram.

### 2. [barbershop_bot](barbershop_bot) — Telegram-бот записи для барбершопа

Бот принимает записи клиентов по схеме «услуга → дата → время», скрывает занятые слоты, позволяет отменять визиты, уведомляет владельца и шлёт клиентам напоминания накануне записи. Настройки салона (услуги, цены, расписание) вынесены в `settings.json`.

- **Технологии:** Python 3, aiogram 3, SQLite.
- **Особенности:** сцена записи с навигацией «назад», команды владельца `/today` и `/week`, напоминания за день до визита.
- Отдельный репозиторий с историей коммитов: <https://github.com/savosiii/barbershop-telegram-bot>

### 3. [wb_cards_bot](wb_cards_bot) — Telegram-бот генерации карточек товаров WB / Ozon

Бот пошагово собирает информацию о товаре и создаёт SEO-название, ключевые слова, описание в выбранном тоне и Excel-файл готовой карточки. Хранит историю последних карточек пользователя.

- **Технологии:** Python 3, aiogram 3, SQLite, openpyxl.
- **Особенности:** шаблонный генератор с настраиваемыми тонами, экспорт карточки в `.xlsx`.

## Общее

- Все проекты запускаются на Windows 10/11 с Python 3.10+.
- Токены и личные настройки хранятся в `.env` (в репозиторий не попадают, есть `.env.example`).
- Подробные инструкции по запуску — в README внутри каждой папки проекта.

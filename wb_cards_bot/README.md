# Telegram-бот генерации карточек WB / Ozon

Бот пошагово собирает информацию о товаре и создаёт:

- SEO-название;
- список ключевых слов;
- описание в выбранном тоне;
- Excel-файл с готовой карточкой;
- историю последних карточек пользователя.

Технологии: Python, aiogram 3, SQLite и openpyxl.

> Текущая версия использует шаблонный генератор в `generate.py`. Внешняя нейросеть или LLM не подключена. Перед публикацией на маркетплейсе результат нужно проверить и отредактировать.

## 1. Что понадобится

- Windows 10/11.
- Python 3.10 или новее: <https://www.python.org/downloads/>. При установке включите **Add Python to PATH**.
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).

`OWNER_ID` и другие настройки владельца для этого проекта не требуются.

## 2. Установка и запуск на Windows

### 2.1. Откройте папку проекта

```bat
cd "C:\Projects\работа\wb_cards_bot"
```

Выполняйте запуск из этой папки: база `cards.db` и Excel-файлы создаются в текущей рабочей директории.

### 2.2. Создайте виртуальное окружение и установите зависимости

```bat
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если виртуальное окружение уже создано, достаточно выполнить вторую команду.

### 2.3. Настройте токен

Скопируйте пример и откройте файл для редактирования:

```bat
copy .env.example .env
notepad .env
```

Замените демонстрационное значение на токен от `@BotFather`:

```dotenv
BOT_TOKEN=123456:ABC-your-real-token
```

Кавычки и пробелы вокруг `=` не нужны. Не публикуйте `.env` и токен бота.

### 2.4. Запустите бота

```bat
venv\Scripts\python.exe bot.py
```

Не закрывайте терминал, пока бот нужен пользователям. Для остановки нажмите `Ctrl+C`.

Откройте своего бота в Telegram, нажмите **Start** или отправьте `/start`.

## 3. Как создать карточку

1. В главном меню нажмите **«✨ Сгенерировать карточку»**.
2. Введите название товара, например:

   ```text
   Термокружка 500 мл
   ```

3. Введите категорию, например:

   ```text
   посуда
   ```

4. Перечислите свойства через запятую, точку с запятой или с новой строки. Рекомендуется 3–6 конкретных характеристик:

   ```text
   сталь 316, 500 мл, не проливается, держит тепло 12 часов, крышка с поилкой
   ```

   Бот не примет меньше трёх свойств. Если указано больше восьми, в генерации используются первые восемь.

5. Выберите тон описания:
   - **Сдержанный, деловой**;
   - **Яркий, эмоциональный**;
   - **Минималистичный, лаконичный**.
6. Дождитесь предпросмотра: названия, ключевых слов и описания.
7. Нажмите **«📥 Скачать Excel»**, чтобы получить файл `.xlsx` в Telegram.

После завершения можно создать ещё одну карточку или вернуться в меню.

## 4. История и повторная выгрузка

1. В главном меню нажмите **«📁 Мои карточки»**.
2. Бот покажет до 10 последних карточек текущего пользователя.
3. Нажмите кнопку **«📥 Excel: …»** рядом с нужным товаром.

Каждый пользователь видит только свою историю. Команды удаления карточек и очистки истории в интерфейсе пока нет.

## 5. Что находится в Excel

Файл `card_<ID>.xlsx` содержит лист **«Карточки»** с пятью колонками:

| Колонка | Содержимое |
|---|---|
| `Товар` | Исходное название товара |
| `Категория` | Введённая категория |
| `Название (SEO)` | Сгенерированное название |
| `Ключевые слова` | Ключевые слова через запятую |
| `Описание` | Текст с преимуществами и выбранным тоном |

Это универсальная таблица проекта, а не гарантированный официальный шаблон Wildberries или Ozon. Перед массовой загрузкой сверьте названия и порядок колонок с актуальным шаблоном конкретного маркетплейса и категории. Обязательные характеристики, артикул, баркод, цена, остатки, габариты и медиа в текущий файл не добавляются.

## 6. Как формируется результат

В `generate.py`:

- SEO-название собирается из товара и первых двух свойств, затем сокращается до 60 символов;
- ключевые слова включают свойства, слова для категории и поисковые фразы с названием товара;
- описание состоит из вступления, списка преимуществ и заключения;
- повторяющиеся ключевые слова удаляются с сохранением порядка.

Для категорий `одежда`, `электроника`, `посуда`, `косметика` и `товары для дома` есть отдельные наборы слов. Для остальных категорий используются универсальные слова «высокое качество», «практичность», «надёжность».

## 7. Настройка генератора

| Задача | Где менять |
|---|---|
| Добавить слова для новой категории | `generate.py`, словарь `CATEGORY_WORDS` |
| Изменить вступления и заключения | `generate.py`, `TONE_OPENERS`, `TONE_CLOSERS` |
| Изменить названия кнопок тонов | `bot.py`, словарь `TONES` |
| Изменить длину SEO-названия | `generate.py`, вызов `_trim(title, 60)` |
| Изменить колонки и ширину Excel | `export_xlsx.py` |
| Изменить тексты диалога | `bot.py` |

Пример добавления категории:

```python
CATEGORY_WORDS = {
    # существующие категории...
    "спорт": ["для регулярных тренировок", "удобно использовать", "прочные материалы"],
}
```

Ключ категории сравнивается с введённым текстом в нижнем регистре, поэтому для автоматического совпадения пользователь должен ввести категорию точно как ключ, например `спорт`.

После изменения `.py`-файлов остановите и заново запустите бота.

## 8. Данные и резервное копирование

| Файл | Назначение |
|---|---|
| `cards.db` | SQLite-база с карточками всех пользователей; создаётся автоматически |
| `card_<ID>.xlsx` | Excel-файлы, созданные при выгрузке |
| `.env` | Секретный токен Telegram-бота |
| `generate.py` | Правила шаблонной генерации |
| `export_xlsx.py` | Формирование Excel |
| `bot.py` | Диалог, история и обработчики Telegram |

Для резервной копии остановите бота и скопируйте `cards.db`, нужные `.xlsx`, `.env` и исходные файлы. `.env` передавайте только по защищённому каналу.

Если `cards.db` отсутствует, при следующем запуске создаётся новая пустая база. Не удаляйте существующую базу, если история ещё нужна.

## 9. Постоянная работа на сервере

1. Перенесите проект на сервер с Python.
2. Установите зависимости в виртуальное окружение.
3. Создайте `.env` с рабочим токеном.
4. Запускайте `bot.py` как службу с автоматическим перезапуском.
5. Рабочей директорией службы назначьте папку проекта.
6. Настройте резервное копирование `cards.db` и очистку либо архивирование накапливающихся `.xlsx`.
7. Не запускайте одновременно две копии с одним токеном.

Бот использует long polling, поэтому отдельный webhook и открытый HTTP-порт не нужны.

## 10. Подключение LLM в будущем

Точка расширения — функция:

```python
build_card(product: str, category: str, features: list, tone: str) -> dict
```

Она должна возвращать словарь с ключами `title`, `keywords` и `description`. Можно заменить шаблонную реализацию на обращение к LLM, сохранив этот интерфейс; тогда основной диалог в `bot.py` менять не потребуется.

Дополнительно понадобятся безопасное хранение API-ключа, обработка ошибок и таймаутов, контроль расходов и проверка фактических утверждений о товаре.

## 11. Типичные проблемы

### `python` не распознаётся

Установите Python с опцией **Add Python to PATH**, перезапустите терминал или попробуйте `py` вместо `python`.

### Бот сообщает, что нужно хотя бы 3 свойства

Перечислите минимум три непустых свойства через запятую, точку с запятой или с новой строки.

### Ошибка токена или бот не отвечает

Проверьте `BOT_TOKEN` в `.env`, доступ к `api.telegram.org`, интернет и отсутствие второй запущенной копии с тем же токеном. Нажмите **Start** в диалоге с ботом.

### Не создаётся Excel

Убедитесь, что зависимости установлены:

```bat
venv\Scripts\python.exe -m pip install -r requirements.txt
```

Проверьте, что у процесса есть право записи в папку проекта и файл с таким именем не заблокирован другой программой.

### Не находится `cards.db` или созданный `.xlsx`

Запускайте бота из `C:\Projects\работа\wb_cards_bot`. При запуске из другой директории файлы будут созданы там.

### Категория не получает специальные ключевые слова

Проверьте точное написание ключа в `CATEGORY_WORDS` и вводимой категории. После правки перезапустите бота.

### Текст выглядит шаблонно

Это ожидаемо для демо-движка. Добавьте более конкретные свойства товара, измените шаблоны в `generate.py` или подключите LLM. Перед публикацией обязательно проверяйте текст на соответствие реальному товару.
